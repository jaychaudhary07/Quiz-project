## CricketQuiz – Online Cricket Quiz Website

**Project Description:**

CricketQuiz is an interactive quiz website designed for cricket lovers to test their knowledge of cricket players, records, teams, iconic matches, and interesting facts. Users can participate in multiple quiz rounds, select answers, earn points, and view their final scores.

**What I Learned:**
- Understanding and using JavaScript functions.
- Working with arrays and arrays of objects.
- Accessing and managing dynamic data.
- Using loops and conditional statements.
- Handling button click events.
- Displaying quiz questions and options dynamically.
- Managing user answers and calculating scores.
- Improving logical thinking and problem-solving skills.

**Key Features:**
- Multiple cricket quiz categories.
- Dynamic questions and answer options.
- Interactive option selection.
- Score calculation and result display.
- Leaderboard section.
